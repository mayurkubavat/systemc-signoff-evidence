# Agent pilot results (SystemC/UVM-SystemC maintenance tasks)

15 tasks from fix and feature branches of UVM-SystemC (14) and SystemC (1). The agent starts at the base commit with an issue-style description; grading restores the branch's hidden regression test and compares its output with the golden log. Arms: `shell` (shell and file tools) and `tools` (plus the scbench MCP server: build, list_tests, run_test, run_regression, query_coverage, randomize_check). 60-turn cap, 1 h timeout. vendor model runs use the vendor CLI in an isolated home, where web search cannot be disabled. Generated by `analysis/results2027.py`.
